Автономно проведи аудит и улучшение frontend этого проекта.

Работай непосредственно с существующим приложением, не делай новый дизайн
с нуля без необходимости.

Самостоятельно:
1. изучи frontend и дизайн-систему;
2. запусти приложение;
3. открой его через Playwright;
4. проверь все основные экраны и пользовательские сценарии;
5. сделай screenshots desktop и mobile;
6. найди визуальные, responsive и UX-проблемы;
7. расставь их по приоритету;
8. исправляй их итеративно;
9. после каждой существенной группы изменений снова визуально проверяй приложение;
10. проверяй browser console и network errors;
11. запускай lint/tests/build;
12. используй reviewer для независимой проверки результата.

Не останавливайся после первого улучшения.
Выполняй цикл:

inspect → prioritize → implement → run → visually inspect → review → fix

пока дальнейшие изменения не перестанут давать заметное улучшение либо пока
не останутся только субъективные изменения без очевидной пользы.

Не запрашивай моего подтверждения для обычных инженерных решений.
Не изменяй backend/API без необходимости.
Не выполняй git push.
Не выполняй destructive git operations.

В конце дай:
- что было найдено;
- что изменено;
- что визуально проверено;
- какие проверки прошли;
- какие проблемы остались.
