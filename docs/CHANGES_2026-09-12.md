# Изменения 2026-09-12 — картинки, свои линии, полный лог, мобильный вид, RU/EN

Дата: 2026-09-12. Все 6 пунктов из запроса реализованы, `pnpm verify` и `pnpm e2e` зелёные.
Перед каждым пунктом решение перепроверялось (альтернативы и выбор — ниже).

## 1) Подключены картинки карт

**Было:** в `apps/web/public/cards/` лежали 72 PNG + `cards.csv`, но UI их нигде не использовал —
карты и фишки были чисто текстовыми.

**Стало:**
- Новый `apps/web/src/app/card-art.ts`: `cardArtUrl(cardId)` → `/cards/<id>.png` (same origin, работает
  и в dev, и в LAN-сборке), `hideBrokenArt()` — прячет битую картинку, остаётся текстовый плейсхолдер.
- `card.component.ts` (рука): арт-баннер 88px над текстом карты.
- `game.component.ts` (стол): миниатюра `.thumb` на каждой фишке юнита/здания с обеих сторон.
- Все `<img>` — `loading="lazy"` + скрытие по `error`, вёрстка без картинок не едет.

**Проблема в данных:** в каталоге 87 карт, артов было 72. 15 карт M1/M2-пасса без артов получили
**временные stand-in** того же семейства (карта — ближайший аналог):
`zombie-plague-bearer→zombie-plague` (та же семья — переименование), `power-stasis-field→power-overclock`,
`power-terror-raid→power-scorch`, `universal-demolition-volunteer→universal-mercenary`,
`universal-drill-sergeant→universal-guard`, `antlion-tunnel-harrier→antlion-hunter`,
`antlion-chitin-skirmisher→antlion-guard`, `antlion-nectar-swarm→antlion-swarm`,
`combine-riot-marshal→combine-metrocop`, `combine-metro-bouncer→combine-elite`,
`rebel-propaganda-runner→rebel-scout`, `rebel-wrench-tinker→rebel-engineer`,
`zombie-rotting-warden→zombie-brute`, `wraith-phantom-harrier→wraith-stalker`,
`guardian-sacred-sentinel→guardian-sentinel`.
Маппинг — в `ART_ALIAS`, удалить его — одна правка, когда появятся настоящие PNG
(положить `/cards/<card-id>.png`, без изменений сборки: `angular.json` уже отдаёт всю `public/`).

**Альтернатива (отклонена):** генерировать 15 PNG прямо сейчас — нечем (офлайн), плейсхолдеры-SVG
выглядели бы хуже, чем тематически близкий арт. Вместо этого в `cards.csv` дописаны 15 строк
в том же формате (`card-id,name,faction,kind,tier,cost,ai-prompt`) — теперь там все 87 карт,
промпты собраны из тех же атомов (faction cue / tier / stats), валидация скриптом:
88 строк, 7 полей, id уникальны, покрытие каталога 87/87.

**Редизайн (второй проход по отзыву):** uniform-рамки `aspect-ratio: 4/3` на картах руки (все арты
строго одного размера, битый файл = тинтованный плейсхолдер того же размера), фишки стола —
горизонтальные (квадратный арт 84px десктоп / 64px мобайл + текст справа, здания 56px), длинные
названия обрезаются многоточием. Проверено DOM-замерами: 5/5 рамок руки 134×101, фишки 84×84
(десктоп) и 64×64 (мобайл), тултипы показываются по hover как раньше, скролла страницы нет.

**Третий проход:** исходники — портреты 768×1024, поэтому рамка стала портретной 4/5 во всю ширину
карты, а название переехало на градиентную подложку поверх арта; высота карт в ряду выравнивается
flex-stretch (160×327 у всех).

**Арт-аудит в бою (`pnpm e2e:art`, новый `e2e/art.mjs`):** изолированные серверы, короткое соло
(юниты и здания доходят до стола), затем DOM-замеры: uniform боксов, загрузка всех картинок,
средняя яркость каждого арта через canvas, hover-тултип, модалка лога, мобайл без скролла, ноль
ошибок консоли; скриншоты в `e2e/artifacts/` (игнорируются гитом). Аудит нашёл мутно-тёмные арты
(power-salvage lum 32): все 72 PNG прогнаны через единый lift (saturation 1.18, contrast 1.1,
brightness +0.08, запечено GDI+ ColorMatrix — осторожно: там row-векторы, оффсеты в последней
СТРОКЕ; вариант со столбцом затемняет). Итог: яркость 56–138, все чеки зелёные.

**Проверено (первый проход):**
браузер: 5/5 артов руки `naturalWidth 768`, stand-in Rebel Scout на Propaganda Runner грузится,
0 сетевых ошибок, 0 ошибок консоли.

## 2) Свои линии у каждого игрока (включая ИИ и соперника)

**Было:** 4 общие линии выбирал только создатель комнаты; второй игрок и ИИ молча получали чужие линии.

**Решение (выбрано после перепроверки):** честная асимметрия — каждая сторона выбирает СВОИ 4 линии.
Позиция `i` поля спаривает `i`-ю линию стороны A с `i`-й линией стороны B; типы сторон могут различаться.
Отклонённая альтернатива — «каждый предлагает, поле общее» — не выполняла требование буквально
(«не должны быть одинаковые 4 линии у всех»).

- **Движок (`game-core`):** `LaneState.type` → `LaneState.sideTypes: Record<PlayerId, LaneType>`
  (то же в `ClientLaneState`); `createGame` принимает `laneTypesByPlayer: { first, second }`,
  каждая сторона валидируется (`INVALID_LANE_TYPES`) и нормализуется независимо; без него —
  зеркальное поле из `config.laneTypes` (все старые тесты и дефолтные комнаты не изменились).
  Колоды строятся **на игрока** (свои фракции + universal); юниты/здания кладутся по типу
  **своей** стороны; фракционные силы требуют фракцию в **своём** наборе.
- **Сервер:** место хранится поседлово (`RoomPlayer.laneTypes` вместо общего `Room.laneTypes`);
  `room:create` принимает `aiLaneTypes` (ИИ; по умолчанию зеркалит человека),
  `room:join` принимает `laneTypes` (второй игрок; по умолчанию зеркалит создателя — старые клиенты работают);
  `roomView` отдаёт линии каждого игрока; рематч хранит оба набора.
  Попутно: `joinRoom` теперь валидирует комнату/линии ДО `leaveBySocket` (раньше вход по битому коду
  ронял текущую комнату звонящего — та же гарантия, что уже была у `createRoom`).
- **Лобби:** пикер вынесен в dumb-компонент `qcw-lane-picker` (тот же мультивыбор с повторами);
  три пикера — «ваши», «линии ИИ» (+ кубик 🎲 случайного набора) и «свои 4 для входа»;
  пре-гейм вид комнаты показывает линии каждого игрока.
- **Стол:** шапка линии — один тип при симметрии (как раньше), иначе `вы: X · враг: Y` с акцентами сторон;
  рамка линии — по своей стороне.
- **e2e:** `e2e.mjs` — флаг `--lang=en-US` (см. п.5: иначе в RU-окружении падают ассёрты на имена линий).

**Проверено:** game-core 149/149 (+7 новых асимметричных), server 46/46 (+4 новых: свои линии
второго игрока, свои линии ИИ, битые входы, рематч), сокет-smoke lock-step до победы зелёный,
`pnpm e2e` 3/3, живой браузер: соло «классика vs antlion/combine/rebel/guardian» — 4-я линия
`you: zombie · foe: guardian`, ИИ сыграл Drill Sergeant из своей antlion-колоды, onPlay-урон по герою
прошёл (29 HP), карта легла в rebel-линию с миниатюрой.

## 3) Полный лог

**Было:** только последние 6 строк в футере; движок хранил максимум 40 записей.

**Стало:** кнопка `Полный лог (N)` → модалка со ВСЕМИ retained-записями (`#seq + текст`), список
скроллится внутри модалки; закрытие по кнопке/бэкдропу; retention движка поднят 40 → 500
(снапшоты маленькие, +~десятки КБ в худшем случае — приемлемо для MVP без event-sourcing).
Состояние модалки — локальный сигнал, протокола не касается.

**Проверено:** модалка живьём показала все 9 записей матча; порядок и тексты совпадают с движком.

## 4) Страница не скроллится на мобильном

**Было:** `.game-shell { min-height: 100vh }` + контент выше вьюпорта → скроллилась вся страница.

**Стало (только `≤850px`, десктоп не тронут):** `.game-shell { height: 100dvh; overflow: hidden }`,
сетка `auto auto 1fr auto auto auto`; растут и скроллятся ВНУТРИ: стол (по обеим осям),
рука (`max-height 28dvh`), hint/лог (`12dvh`). Слоты ужаты до 118px, паддинги уменьшены.

**Проверено (390×844, живой матч):** `scrollHeight == innerHeight == 844`, `scrollWidth == 390`
(ни вертикального, ни горизонтального скролла страницы), shell ровно 844px `overflow:hidden`,
стол 218px + внутренняя прокрутка, все контролы доступны, 0 ошибок консоли.

## 5) Перевод всего приложения на русский

**Стало:** новый `I18nService` без зависимостей — плоский словарь EN/RU, сигнал `lang`,
персист `qcw.lang`, авто-детект `navigator.language=ru-*` (иначе EN). Переключатель `RU/EN`
в шапке лобби и в шапке матча, применяется мгновенно без перезагрузки.
Переведено: весь хром (лобби, стол, модалки, кнопки, хинты, названия линий/фракций:
antlion→«муравьиный лев», combine→«альянс», rebel→«повстанец», zombie→«зомби»,
guardian→«страж», wraith→«призрак»).
**Ограничение (задокументировано в коде):** НЕ переводятся названия/описания карт, журнал движка
и ошибки сервера — это авторитетные английские строки из game-core/сервера.

**Проверено:** RU по умолчанию при `ru-RU`, мгновенное EN/RU туда-обратно с сохранением пиков линий
и `qcw.lang`, скриншоты RU-лобби/матча, `pnpm e2e` зелёный с `--lang=en-US`.
